# HTML 课程设计报告

在项目根目录执行：

```bash
open docs/demo/index.html
```

也可以直接用浏览器打开 `index.html`。这是离线单文件演示，无需安装前端依赖、启动服务或配置 API 密钥。

共 23 页，其中正文 21 页（含封面），附录 2 页。正文按课设报告组织：研究问题与范围、三组对照、测试管理、系统实现、隔离约束、数据与指标、实验结果、成功与失败案例、成本、交付、要求完成对照及结论。实际操作命令放在附录。

070 单独用两页解释 A 为什么取错第一项、B 为什么仍没改对、C 收到哪条报错后改了哪个条件。其他案例也分别解释 A/B/C 的代码行为，不只展示通过与失败标签。

第 17 页专门演示课题要求的“公开测试通过但隐藏测试失败”。它使用已有的空白规范化演示函数，已在断网、只读 Docker 中独立验证：5 个公开测试通过、5 个隐藏测试失败。该演示不是 001 的模型生成结果，不计入正式效果统计。验证记录见 [validation/whitespace-demo.json](validation/whitespace-demo.json)。

第 20 页逐项对应课题要求，注明已实现内容与验收记录；第 21 页给出结论和限制。附录 A/B 分别保留其他真实修复案例和运行步骤。

## 操作

| 操作 | 快捷键 / 入口 |
| --- | --- |
| 上 / 下一页 | 方向键、PageUp / PageDown、底部按钮 |
| 首页 / 尾页 | Home / End |
| 章节目录 | O 或右上角“目录” |
| 本页讲稿 | N 或右上角“讲稿” |
| 全屏 | F 或右上角“全屏” |
| 关闭面板 | Esc |
| 导出 PDF | 右上角“打印”，打印目标选择“另存为 PDF” |
| 案例回放 | 附录 A（第 22 页）切换 070 / 097 / 125，点击“播放过程” |

手机可纵向阅读当前页，并横向滑动翻页。表格和时序图保持自身横向滚动。打印时展开全部 23 页，案例页保留当前选中的案例并展示最终修改。投屏时请关闭讲稿，讲稿会直接显示在页面右下角。

## 数据口径

演示冻结于 `results/experiments/20261101_001`，模型为 `deepseek-flash`，164 题、1 次重复、492 条策略记录。它不会自动切换到最新批次。

- 整体隐藏通过题数：A=142，B=145，C=148，分母均为 164。
- 共享首轮公开失败的 12 题中，B/C 最终隐藏通过数分别为 3/6。
- 070、097、125 是本次全部 C 独赢案例，代码和公开反馈取自已保存轨迹。
- 3 道流程演示题合计 30 个 pytest 测试函数，不是 30 道修复题；正式集的 164 个修复任务单独计数。
- 20 道自建补充题未计入本次结果。
- 成本区分策略等价成本和物理实际调用，不把共享首轮重复计入整批实际费用。

HTML 内置文字、样式、脚本、图表与案例摘录，不发起网络请求，也不执行候选函数。单独复制 HTML 仍能展示全部演示内容；来源链接按仓库相对位置指向原始文件，核对证据时应保留 `docs/demo/` 的目录位置。
