# HTML 课程设计报告

在项目根目录执行：

```bash
open docs/demo/index.html
```

也可以直接用浏览器打开 `index.html`。这是离线单文件演示，无需安装前端依赖、启动服务或配置 API 密钥。

共 23 页，其中正文 22 页（含封面），附录 1 页。正文从项目背景开始，按实际汇报人顺序组织：

1. 组长：研究问题、总体架构、A/B/C 对照设计、运行编排；
2. 模型负责人：模型输入输出、`submit_solution`、测试反馈修复循环；
3. 沙盒负责人：Docker 隔离、公开/隐藏测试、安全与可复现性，只讲执行机制；
4. 研究负责人：前期试跑、数据集搜索、指标设计、运行实验、全量结果以及全部案例；
5. 组长：总体收尾。

模型负责人段落只讲输入输出协议、`submit_solution` 校验和策略状态机，不展示具体题目。070 的两页完整案例移到研究负责人段落，解释共享首轮为什么仍失败，以及 B/C 收到不同信息后如何分化。

“公开测试通过但隐藏测试失败”的空白规范化案例也统一放在研究负责人段落分析。它已在断网、只读 Docker 中独立验证：5 个公开测试通过、5 个隐藏测试失败。该演示不是 001 的模型生成结果，不计入正式效果统计。验证记录见 [validation/whitespace-demo.json](validation/whitespace-demo.json)。

研究负责人附录位于第 22 页，保留其他真实修复案例；第 23 页再由组长完成总体收尾。

## 操作

| 操作 | 快捷键 / 入口 |
| --- | --- |
| 上 / 下一页 | 滚轮、↑ / ↓ / ← / →、PageUp / PageDown、底部按钮 |
| 首页 / 尾页 | Home / End |

| 全屏 | F 或右上角“全屏” |

| 导出 PDF | 右上角“打印”，打印目标选择“另存为 PDF” |

## 数据口径

演示冻结于 `results/experiments/20261101_001`，模型为 `deepseek-flash`，164 题、1 次重复、492 条策略记录。它不会自动切换到最新批次。

- 整体隐藏通过题数：A=142，B=145，C=148，分母均为 164。
- 共享首轮公开失败的 12 题中，B/C 最终隐藏通过数分别为 3/6。
- 070、097、125 是本次全部 C 独赢案例，代码和公开反馈取自已保存轨迹。
- 前期 HumanEval 30 道题试跑为 30/30，因公开首轮直接通过而没有触发反馈循环；早期 Qwen 0.5B 则无法稳定遵守 `submit_solution` 协议。这两项用于解释为什么改用 FeedbackEval。
- 正式主实验使用 FeedbackEval-HumanEval 全量 164 道修复任务；DeepSeek 的 A/B/C 最终隐藏通过数为 142/145/148。
- 精选 30 题补充批次使用独立首轮协议，最终公开为 18/25/26，最终隐藏为 12/18/18。它是压力测试和边界检查，不作为第二次总体优势证明。
- 成本区分策略等价成本和物理实际调用，不把共享首轮重复计入整批实际费用。

HTML 内置文字、样式、脚本、图表与案例摘录，不发起网络请求，也不执行候选函数。单独复制 HTML 仍能展示全部演示内容；来源链接按仓库相对位置指向原始文件，核对证据时应保留 `docs/demo/` 的目录位置。
