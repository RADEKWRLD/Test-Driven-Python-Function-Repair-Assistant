# DeepSeek 最小接入测试结果

测试日期：2026-10-30。范围仅为一道演示题 `chunk-list`，分别运行三组；没有启动 50 题正式实验。

本文件是项目精简前的历史实测记录，原始结果保留不变。精简后的日志为普通 JSONL、报告为 Markdown 和四张图；历史哈希链验证不代表当前实现仍提供防篡改功能。

## 配置

- 运行环境：本机 Ubuntu-22.04（WSL2），项目 Python 3.12.16，Docker Desktop Linux 引擎。
- 接口：DeepSeek 官方 API；请求及响应中的模型名均为 `deepseek-flash`。
- 显式关闭思考模式，temperature=0，单次输出上限 2048 token，请求超时 120 秒。
- 三组总提交预算为 1/3/3；公开通过后提前停止。本次三组均只实际提交一次。
- API 响应没有返回独立于别名的具体权重版本；正式实验仍须保留运行日期和提供方版本信息，不能宣称模型版本完全锁定。

## 实测结果

| 策略 | 模型调用 | 最终公开用例 | 最终隐藏用例 | 总 token | 模型请求耗时 | 整个 run 耗时 |
| --- | ---: | --- | --- | ---: | ---: | ---: |
| A：single-shot | 1 | 5/5 | 5/5 | 831 | 0.832 秒 | 7.077 秒 |
| B：retry-without-feedback | 1 | 5/5 | 5/5 | 833 | 1.211 秒 | 7.206 秒 |

三组总计：

- 实际模型调用 3 次，低于最多 7 次的预算。
- 输入 2181 token，输出 316 token，合计 **2497 token**。
- 模型请求累计 2.935 秒；修复与隔离评分完整流程 **21.349 秒**。
- 公开/隐藏评分、代码快照和事件日志均生成；三个日志的哈希链完整，未发现 API Key 写入事件日志。

## 费用观察

调用前后官方余额接口的 CNY 余额差为 **0.00 元**。该观察不能解释为模型调用免费：本次调用量小，余额接口显示精度、入账延迟或同账号其他请求都可能影响余额差。

原始 token 与缓存命中用量已保存。没有锁定计价配置，逐 run 的 `currency_cost` 继续保持 null；准确扣费应以供应商账单为准。

## 能说明和不能说明的事

本次证实：密钥和模型可用，WSL 能访问官方 API，三种策略均能完成生成、Docker 公开测试、独立隐藏评分及日志记录。

三组在第一次提交时就成功，因此本次没有实际触发后续失败反馈，不足以比较反馈是否提高成功率，也不足以推算 50 题的真实总费用和耗时。失败反馈控制逻辑已有开发测试覆盖，正式效果仍须另行实验。
