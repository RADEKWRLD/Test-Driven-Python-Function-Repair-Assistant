# 精选 30 题实验集

本目录从 `benchmarks/feedbackeval-humaneval-full` 的 164 道题中选出 30 道，用于后续小规模、高区分度的修复实验。题目文件保持原样复制，包括初始错误实现、公开测试、隐藏测试和任务清单。

筛选依据是两批已有实验：

- `results/experiments/20261101_001`：DeepSeek，164 道题均为有效运行。
- `results/experiments/20261113_002`：Qwen，160 道题为有效运行；4 道基础设施异常题不参与筛选。

## 筛选结构

| 主类别 | 数量 | 题号 | 选择理由 |
| --- | ---: | --- | --- |
| 跨模型持续困难 | 9 | 032, 050, 076, 114, 124, 132, 145, 147, 154 | 两批实验中三种策略的最终隐藏测试都失败，适合观察困难样本的修复上限。 |
| 策略敏感 | 8 | 070, 089, 097, 121, 122, 125, 127, 163 | 至少一批实验中，测试反馈策略 C 的最终隐藏测试通过，而无反馈重试 B 失败。 |
| 重试可修复 | 7 | 038, 063, 069, 119, 130, 138, 146 | 至少一个模型首轮失败，但 B 或 C 经重试后通过隐藏测试。 |
| 模型敏感或隐藏陷阱 | 6 | 049, 082, 091, 108, 111, 126 | 两个模型的结果明显不同，或出现公开测试通过但隐藏测试失败。 |

完整的机器可读清单见 `selection-manifest.json`。

## 运行

```bash
make experiment TASKS_DIR=experiment
```

## 使用限制

这是依据既有模型结果刻意富集困难题和高区分度题得到的压力测试集，适合比较策略、回归测试和快速迭代。它不是从 164 题中随机抽样的无偏子集，因此不应使用这里的通过率估计完整 HumanEval 题库的总体通过率。
